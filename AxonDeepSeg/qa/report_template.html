Single Axon Inspection

How to use
  1. Set the filters below to hide the objects you don't want to review (for example very small objects).
  2. Go through the axons with the arrow keys, the list on the right, or by clicking an axon in the image. Drag the image to look around, scroll to zoom, hold T to see the image without the segmentation.
  3. Flag each axon you look at: 1 good, 2 needs correction, 3 delete, 0 clear. P pins an axon to come back to it later.
  4. Click Export flags (CSV) when you are done and send the file. Flags are also saved in this browser as you go.
The axon ID is the row index of the morphometrics file, the same number shown by the napari plugin. Exported flags can be applied to the morphometrics with axondeepseg_filter --qa-flags.
